# Grape yield prediction project

Place your `.xlsx` or `.csv` source files in this directory:

- POT yield report (`*POT*.xlsx` or any file with `YIELD ESTIMATION` columns)
- Harvest data (Hebrew `כרם` column or English harvest headers)
- Cluster data (`CLUSTER COUNT`)
- Agricultural archive (`WEATHER STATION`, block metadata)
- Weather workbooks (`קוד תחנה` / station code)

The loader auto-detects file types from column headers.
